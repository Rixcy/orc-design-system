Stepper

Phase pills with aria-current and a text affix for done. Never color alone.

Utilities

Opt-in CSS, exported from the package like everything else. This page uses both.

  • typography.css: the six-role type scale above, as --orc-type-* properties and .orc-type-* classes.
  • scrollbar.css: orc's bordered scrollbar; add .orc-scrollbar to any scroll container.
