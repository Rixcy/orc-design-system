# Space & radius

A five-step 4px space scale and three radii. Values are read live from
`src/styles/tokens.css`.

## Space

<Space />

Steps are multiples of 4px: use `--orc-space-2` for control padding,
`--orc-space-3` for gaps between controls, `--orc-space-4`/`5` for section
rhythm. Anything that needs a value between two steps usually wants the
smaller step.

## Radius

<Radii />

`--orc-radius-sm` for small inline controls, `--orc-radius-md` for buttons,
panels and dialogs, `--orc-radius-pill` for chips and anything capsule-shaped.

## Focus

Focus is a token too, so every component's focus ring matches:

- `--orc-focus-ring` — `2px solid var(--orc-green)`
- `--orc-focus-offset` — `2px`

```css
.thing:focus-visible {
  outline: var(--orc-focus-ring);
  outline-offset: var(--orc-focus-offset);
}
```

Components use `:focus-visible`, never `:focus`, and keep the ring visible in
forced-colors mode by falling back to `Highlight`.
