# Typography

Two families, six roles. Inter carries the interface; JetBrains Mono carries
anything the machine wrote. The scale below is read live from
`--orc-type-*` in `src/styles/typography.css`.

<Specimen />

## Using it

`src/styles/typography.css` is opt-in — import it for the custom properties,
the `.orc-type-*` utility classes, or both:

```js
import "@orc-tools/orc-design-system/tokens.css";     // --orc-font-sans / --orc-font-mono
import "@orc-tools/orc-design-system/fonts.css";      // packaged Inter + JetBrains Mono
import "@orc-tools/orc-design-system/typography.css"; // --orc-type-* + .orc-type-*
```

```css
.run-title {
  font: var(--orc-type-headline);
}
```

Prefer a role over ad-hoc sizes. If a piece of text does not fit one of the six,
that is usually a sign the layout wants rethinking rather than a seventh role.

## Families

- `--orc-font-sans` — Inter, then the platform sans stack
- `--orc-font-mono` — JetBrains Mono, then the platform mono stack

Both faces ship as variable `woff2` files and are only loaded when
`fonts.css` is imported; without it, the stacks fall back to system fonts and
nothing breaks.
