# Colour

Every colour ships as a CSS custom property on `:root`. `src/theme/orc-tokens.json`
is the single source: `scripts/sync-theme.mjs` generates `src/styles/tokens.css`
from it, and this page renders the same JSON — so nothing here can drift.

Use the semantic name, never the hex. `--orc-accent` follows the theme;
`#2d6983` does not.

## Derived colours

`tokens.css` also derives surface-aware values with `color-mix()`. These are
the ones to reach for when text sits on a coloured surface:

- `--orc-muted-strong` — `--orc-muted` mixed toward `--orc-heading`
- `--orc-accent-text` — `--orc-accent` mixed toward `--orc-heading`
- `--orc-green-text`, `--orc-red-text`, `--orc-yellow-text`, `--orc-purple-text` —
  the matching hue mixed toward `--orc-heading`
- `--orc-gate` — `--orc-orange` mixed toward `--orc-heading`

## Theming

`:root` carries Orc day. `[data-theme="dark"]` (or `prefers-color-scheme: dark`
with no explicit `data-theme`) swaps in Orc night. Consumers switch themes with
the exported theme controller, or by setting `data-theme` themselves — the
components read only custom properties, so they follow automatically.
