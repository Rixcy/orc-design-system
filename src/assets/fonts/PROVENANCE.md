# Font provenance

The packaged variable fonts are copied from Orc's local UI assets:

- `inter-latin-wght-normal.woff2` — Inter variable font, Latin subset.
- `jetbrains-mono-latin-wght-normal.woff2` — JetBrains Mono variable font, Latin subset.

Both fonts are distributed under the SIL Open Font License 1.1 in `LICENSE.txt`.
Importing `fonts.css` is opt-in; `tokens.css` keeps platform fonts as its default.
